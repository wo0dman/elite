## ⚡ ЧТО ЭТО

**ELITE** — это не просто игра. Это **симулятор галактики**, в которой ты — пилот «Кобры Mk III» с сотней кредитов в кармане и голодом, который не утолить торговлей продовольствием.

Восемь галактик. 2048 звёздных систем. Империя пала триста лет назад, оставив после себя гиперприводы, таблицу товарных цен и пустоту, в которой каждый выживает как умеет.

Ты можешь **торговать**, **охотиться за головами**, **перевозить VIP-пассажиров**, **уничтожать пиратов** и **умирать** — от лазера Вайпера, от столкновения со станцией, от перегрева у звезды. Или — стать легендой.

> *«Звание Элита даётся за 6144 победы. За всю историю его получили немногие. Ты можешь стать следующим.»*

## 🚀 УСТАНОВКА

Никаких зависимостей. Никаких сборок. Никаких `npm install`.

```bash
# Вариант 1 — просто откройте файл
git clone https://github.com/your-username/elite-browser.git
cd elite-browser
# открыть index.html в браузере

# Вариант 2 — локальный сервер (для полного экрана и pointer lock)
python3 -m http.server 8080
# → http://localhost:8080
```

**Требования:** любой современный браузер с поддержкой Canvas и WebAudio. Chrome, Firefox, Safari, Edge.

**Мобильные устройства** поддерживаются — управление адаптировано под тач.

<td width="50%">

### Джойстик и мышь

**Клик по джойстику** → захват (курсор скрыт, pointer lock)
**Движение мыши** → тангаж/крен
**Клик ещё раз** или `Esc` → отпустить

**Пульт пиктограмм** (левый нижний угол) — дублирует все боевые функции:
`ОГОНЬ` · `РАКЕТА` · `БОМБА` · `ГИПЕР` · `СТЫК` · `ТРАКТОР` · `ТЯГА+` · `ТЯГА−`

**Радар** — клик по нему переключает диапазон (2 км → 6 → 20 → 60 → 200 → АВТО).

```
    Безобидный         →  0 побед
    Почти безобидный   →  8
    Слабый             →  24
    Средний            →  44
    Выше среднего      →  150
    Компетентный       →  280
    Опасный            →  520
    Смертоносный       →  1024
    ▓▓▓  ЭЛИТА  ▓▓▓    →  6144
```

*Реалистичная цель на вечер — «Опасный» (520). «Элита» — это марафон.*

## 🛠 ТЕХНИЧЕСКИЕ ДЕТАЛИ

- **Один HTML-файл** — никаких сборок, никаких зависимостей
- **Vanilla JS** — без фреймворков
- **Canvas 2D** — рендер кораблей, планет, звёзд
- **WebAudio API** — синтез всех звуков в реальном времени
- **Pointer Lock API** — захват мыши для джойстика
- **LocalStorage** — сохранения в браузере
- **Процедурная генерация** — по мотивам алгоритмов BBC Elite (галактики, системы, имена)

**Данные и алгоритмы:** [bbcelite.com](https://bbcelite.com) — проект реверс-инжиниринга оригинального кода BBC Micro.
